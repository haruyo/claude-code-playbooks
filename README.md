# claude-code-playbooks

**Claude Code が読み込んで、その手順どおりに作業を進めるための「実行手順書（プレイブック）」集です。**

専門知識がなくても、中小企業の担当者が **自分たちのパソコンで Claude Code に手順書を読ませるだけ** で、マーケティングや分析などの実務を進められることを目指しています。各手順書は「人間（あなた）が読む説明書」ではなく、**Claude Code に読ませて実行させる台本** として書かれています。

---

## 使い方

1. このリポジトリから、やりたいことに合う手順書（`.md`）を選びます（下の[手順書一覧](#手順書一覧)）。
2. お使いの環境に [Claude Code](https://claude.com/claude-code) を用意します。
3. Claude Code に、その手順書ファイルを読み込ませます（ファイルを置いたフォルダで起動し「この手順書どおりに進めて」と伝えるか、中身を貼り付けます）。
4. あとは Claude が上から順に案内します。**人間にしかできない操作（ログイン承認・クリックなど）には `【人間に依頼】` と明記**されているので、その箇所だけ対応すれば完了します。

> 手順書の多くは **無料の範囲で動く**ように設計しています（各手順書の冒頭に費用の記載があります）。

## 取り扱いの注意

- 手順の途中で作られる認証情報（例：`token.json` / `client_secret.json`）は **秘密情報** です。第三者への共有や、公開リポジトリへのコミットは行わないでください（本リポジトリの `.gitignore` で除外しています）。
- 各手順書のコードは **動作実績のあるベース**です。利用するライブラリや API の仕様変更で動かない場合は、Claude が最新情報を確認して必要な範囲で調整します。
